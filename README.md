# 📸 Cloud-App — Портфолио фотографа с защитой водяными знаками

> Веб-приложение для безопасной демонстрации фотографий клиентам с автоматическим наложением цифровых водяных знаков.
>
> _Этот коммит считается финальным и охватывает весь файл `app.py` и обновлённую документацию `README.md`._

## ✨ Возможности

### Для фотографа (администратора)
- 📁 Создание и управление виртуальными папками по проектам/клиентам
- 📤 Загрузка файлов с поддержкой мультизагрузки (drag & drop)
- 👁️ Предпросмотр изображений с водяным знаком в реальном времени
- 🔗 Генерация уникальных защищённых ссылок для клиентов
- 🗑️ Удаление файлов и папок с автоматическим обновлением метаданных
- 🌓 Переключение тёмной/светлой темы интерфейса

### Для клиента
- 🔐 Доступ к галерее только по уникальной ссылке с токеном
- 🖼️ Просмотр изображений в полноэкранном лайтбоксе
- ⌨️ Управление клавиатурой (← → Esc F)
- 🚫 Защита от копирования: блокировка ПКМ, Ctrl+S, перетаскивания
- 💧 Автоматическое наложение водяного знака на все изображения

## 🛠 Технологический стек

| Компонент | Технология |
|-----------|-----------|
| **Backend** | Python 3.10+, Flask 2.3.3, Werkzeug, Pillow 10.0.0 |
| **Frontend** | HTML5, CSS3, Vanilla JavaScript (ES6) |
| **Хранение** | Файловая система + JSON-метаданные |
| **Безопасность** | `secrets.token_urlsafe()`, `secure_filename()` |
| **Развёртывание** | GitHub Codespaces, Docker (опционально), Nginx (prod) |

## 🚀 Быстрый старт

### Вариант 1: Локальный запуск

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Shorokhovv/cloud-app.git
cd cloud-app

# 2. Создайте и активируйте виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/macOS
# или
venv\Scripts\activate     # Windows

# 3. Установите зависимости
pip install -r requirements.txt

# 4. (Опционально) Установите шрифты для водяных знаков
# Ubuntu/Debian:
sudo apt-get install fonts-dejavu-core

# 5. Запустите приложение
python app.py
